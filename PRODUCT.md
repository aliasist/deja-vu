# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers and AI power users who want to search and retrieve past AI coding session history — finding decisions, rules, and conventions from previous sessions.

## Product Purpose

Deja Vu provides session memory search — indexing and searching past AI coding session transcripts. Users can find past decisions, rules, conventions, and code patterns from previous AI sessions.

## Positioning

A memory search tool for AI coding sessions — don't repeat yourself, search what you've already done.

## Operating Context

- Session transcript indexing
- Full-text search across past sessions
- CLI and web interface

## Capabilities and Constraints

- Search past AI session transcripts
- Find decisions, rules, conventions
- Index session metadata

## Brand Commitments

- Name: Deja Vu

## Evidence on Hand

- Source code in src/ with search and history components

## Product Principles

1. **Search-first** — find what you need, don't re-derive it.
2. **Session-aware** — understands AI coding session context.
3. **Fast** — quick search, quick results.
